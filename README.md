Read `AGENTS.md` first. Then read `docs/ARCHITECTURE.md`, `docs/ROADMAP.md`, and `docs/DEVELOPMENT.md`.

- `docs/ARCHITECTURE.md`: target architecture and data flows.
- `docs/ROADMAP.md`: milestones and status.
- `docs/TECHNICAL_DECISIONS.md`: technology choices and trade-offs.
- `docs/DEVELOPMENT.md`: local setup and commands.
- `docs/DATABASE.md`: known schema and migrations.
- `docs/SECURITY.md`: security model and requirements.
- `docs/LEARNING_NOTES.md`: engineering concepts to understand.
- `docs/WORKFLOW.md`: ChatGPT/Codex/project-owner workflow.

These docs were prepared from prior project discussions, not a fresh repository inspection. Verify uncertain details before relying on them.
